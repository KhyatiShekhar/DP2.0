03 · Access Management
03 · SSO + AD/LDAP Mapping
I had to create 50 user accounts manually in the CCS portal. We already have Okta.— backup admin

Enterprise identity paths for CCS.

Cloud services now supports SSO via SAML/OIDC with AD/LDAP group mapping for automatic role assignment.

ReplacesManual user creation in CCS portal
  • SSO providers — Okta, Azure AD, Ping, or any SAML/OIDC app.
  • Group → Role — AD groups map to Helios roles (Admin, Operator, Viewer).
  • Zero manual provisioning — new hires get access via group membership.
  • Consistent — On-Prem uses AD/LDAP already. CCS now matches.
